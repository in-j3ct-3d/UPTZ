**UPTZ** — легковесная, быстрая и безопасная утилита системного обслуживания и диагностики для Windows 10 и 11, написанная на чистом Rust. 

В отличие от традиционных «твикеров» и громоздких программ на Electron или .NET, UPTZ поставляется в виде одного статического исполняемого файла (~15.3 МБ), не требует установки, не висит службой в фоновом режиме, не содержит рекламы и не собирает пользовательскую телеметрию.

Официальный сайт проекта: **[https://uptz.tech](https://uptz.tech)**

## Архитектура и модули

UPTZ состоит из 11 специализированных модулей, работающих напрямую через Win32 API и недокументированные вызовы ядра NT (без промежуточных скриптов и тяжелых библиотек):

| Модуль | Описание и технические детали |
|---|---|
| **Обзор (Dashboard)** | Живой мониторинг загрузки CPU, RAM и подсистемы дисков. Однокликовые действия: сброс кэша Standby-памяти, очистка Temp, сброс DNS-кэша, вызов TRIM для SSD и принудительное создание точки восстановления VSS. |
| **Очистка диска (Cleaner)** | Аудит и безопасное удаление временных файлов (`%TEMP%`, системный Temp, кэш скачиваний Windows Update `SoftwareDistribution`, дампы BSOD/WER, Корзина, кэши браузеров). Защита: фильтр файлов моложе 2 часов и контроль залоченных дескрипторов. Очистка старых дубликатов драйверов в DriverStore через SetupAPI / DISM. |
| **Сброс памяти (Standby Purge)** | Прямой вызов системного API ядра NT (`NtSetSystemInformation` с классом `SystemMemoryListInformation` / `MemoryPurgeStandbyList`) для мгновенной выгрузки сотен мегабайт закешированных страниц перед запуском требовательных игр или приложений. |
| **Автозагрузка (Startup)** | Анализ и управление всеми точками запуска: реестр `Run` / `RunOnce` (`HKCU`, `HKLM`, включая 32-битные ветки `WOW6432Node`), директории автозапуска и Планировщик заданий Windows (Task Scheduler). |
| **Деинсталлятор (Uninstaller)** | Запуск официальных деинсталляторов с последующим глубоким сканированием файловой системы (`ProgramData`, `AppData`, `Common Files`) и реестра для выявления и безопасного удаления оставшихся «хвостов». |
| **Управление службами (Services)** | Взаимодействие с Service Control Manager (SCM). Фильтрация на системные, пользовательские и службы телеметрии. Возможность безопасного отключения с защитой от повреждения критически важных служб ядра Windows. |
| **Диспетчер процессов (Processes)** | Инспекция активных процессов с деталями PID, CPU, памяти и потоков. Поддержка изменения приоритетов, включения EcoQoS (эффективный режим Windows 11), приостановки (suspend), возобновления (resume) и завершения. Защитный белый список исключает случайное завершение системных компонентов (`csrss.exe`, `lsass.exe`, `smss.exe` и др.). |
| **Приватность и телеметрия (Privacy)** | Аудит и отключение встроенных каналов фонового сбора данных: службы DiagTrack, WAP Push, WerSvc, телеметрия CEIP, рекламные идентификаторы и рекомендации меню «Пуск». |
| **Восстановление системы (Repair)** | Быстрый интерфейс для вызова утилит целостности ОС: `sfc /scannow`, `DISM /Online /Cleanup-Image /RestoreHealth`, `chkdsk`, сброс сетевого стека Winsock/TCP-IP, восстановление загрузчика BCD (`bcdedit`, `bcdboot`) и среды восстановления (`reagentc`). Корректно функционирует в средах WinPE / WinRE. |
| **PE Эвристика и аудит (Heuristics)** | Локальный сканер исполняемых файлов: вычисление SHA-256, верификация цифровых подписей через `WinVerifyTrust` / Каталоги подписей, анализ энтропии секций (поиск упаковщиков и крипторов), детект аномалий прав доступа секций (W+X), сверка с эталонным бейслайном доверенных системных файлов. |
| **Консоль быстрого доступа (Terminal)** | Встроенный терминал с набором проверенных команд и диагностических пресетов с возможностью экспорта логов работы. |

## Безопасность и отказоустойчивость

* **Точки восстановления (VSS):** Перед применением деструктивных твиков или удалением системных компонентов инициируется создание теневой копии состояния Windows через `SRSetRestorePointW`.
* **План изменений (Dry-Run):** Любые изменения реестра предварительно отображаются в формате «БЫЛО → СТАНЕТ», предотвращая случайные перезаписи.
* **Резервные копии:** История действий и снапшоты реестра сохраняются локально в `%APPDATA%\UPTimiz\backups\`.
* **Zero Telemetry:** Программа не обращается к внешним серверам для передачи статистики, конфигурации или телеметрии устройства. Все проверки и сканирования выполняются строго локально.
* **Аварийный интерфейс WinPE / GDI:** При запуске в среде восстановления Windows RE или при сбое видеодрайвера программа автоматически переключается на встроенный легковесный Win32 GDI интерфейс (флаг `--gdi`).

## Аргументы командной строки

UPTZ поддерживает запуск со следующими флагами:

```text
uptz.exe [ОПЦИИ]

Опции:
  --gdi              Запуск в режиме облегченного Win32 GDI интерфейса
                     (для сред WinPE, WinRE или при отсутствии GPU/DirectX драйверов)
  --apply-update     Служебный флаг для применения скачанного обновления
  --uninstall        Чистое удаление локальных данных конфигурации программы
```

## Логирование и диагностика

* Файлы журналов сохраняются по пути: `%APPDATA%\UPTimiz\logs\app.log`
* Настройка детализации логов через переменную окружения:
  ```powershell
  $env:RUST_LOG="debug"; .\uptz.exe
  ```
  Допустимые значения: `error`, `warn`, `info` (по умолчанию), `debug`, `trace`.

## Предупреждение SmartScreen и антивирусов

Поскольку UPTZ является бесплатным независимым проектом с открытым исходным кодом, бинарный файл не подписывается дорогостоящим коммерческим сертификатом EV Code Signing ($400+/год). 

При первом запуске Windows SmartScreen или антивирусное ПО могут выдать предупреждение о «неизвестном издателе». Это штатное поведение Windows для новых исполняемых файлов без коммерческой репутации SmartScreen.

* Исходный код полностью открыт для аудита и самостоятельной сборки.
* Отчет проверки на [VirusTotal](https://www.virustotal.com): 0/72 обнаружений.
* Хэш-сумма официального бинарника всегда публикуется в Releases и на [uptz.tech](https://uptz.tech).
