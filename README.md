# UPTZ
UPTZ — быстрая и безопасная утилита на Rust для Windows 10/11. Очистка DriverStore (15–40 ГБ), сброс Standby RAM перед играми, менеджер автозагрузки, удаление софта без хвостов и отключение телеметрии. Без рекламы и фоновых служб. 15 МБ portable. https://uptz.tech
